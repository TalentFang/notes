
```
# 1. 定义所有监听器及其端口
listeners=PLAINTEXT://:9092, CONTROLLER://:9093

# 2. 指定哪个监听器用于Broker间通信
inter.broker.listener.name=PLAINTEXT

# 3. 指定哪个监听器是Controller通信专用
controller.listener.names=CONTROLLER

# 4. 告诉客户端使用哪个地址连接（这里需要替换为你的实际IP或域名）
advertised.listeners=PLAINTEXT://你的对外IP或域名:9092

```
在这个配置里，`9092` 就被明确指定为对内 Broker 通信的端口，而 `9093` 则是 Controller 内部专用端口。你可以根据需要将它们改成任何未被占用的端口[](https://docs.redhat.com/zh-cn/documentation/red_hat_streams_for_apache_kafka/2.7/html/deploying_and_managing_streams_for_apache_kafka_on_openshift/security-str#certificate-authorities-str)。

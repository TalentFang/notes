# AIXDR 密码管理改造方案

## 背景

AIXDR 系统及全栈组件（root/asap 账户、第三方组件）统一使用初始密码 `maxs.PDG~2022`（Redis 使用 `!QAZxsw2#EDC(0Ol1)`），密码硬编码在 16 个 inventory 文件、25+ Jinja2 模板、10+ Ansible task 文件、5 个 vars 文件、3 个 Shell 脚本、2 个 Python 工具中。

### 风险
- **统一密码隐患**：所有核心账户及组件共享同一密码，一旦泄露全范围失陷
- **无法追溯**：无法定位泄露源头
- **业务风险**：代码中写死密码，修改密码后组件连不上导致业务不可用

## 方案决策

| 决策项 | 选择 |
|--------|------|
| 密码模式 | **模式 A：统一强密码**（所有账户同一密码） |
| asap→aixdr 迁移 | **本次不涉及**，后续独立处理 |
| 实施范围 | **maxs-ops 仓库 + 业务代码** |

## 密码规范

- 长度 ≥ 12 位
- 包含大写字母、小写字母、数字、特殊字符（`!@#$%^&*`）
- 禁止包含系统/组件名称（maxs, asap, xdr, redis, kafka, es, clickhouse, minio, mongo, mariadb, vastbase, root, admin）

所有密码统一定义在 `inventory/group_vars/all/secrets.yml`（ansible-vault 加密）。

## 核心设计

### 单一数据源

```
inventory/group_vars/all/secrets.yml (ansible-vault 加密)
    │
    ├── Ansible 模板: {{ ROOT_PASSWORD }}, {{ REDIS_PASSWORD }}, ...
    ├── Shell 脚本:   source password_lookup.sh && get_password ROOT_PASSWORD
    ├── Python 工具:  from password_provider import get_redis_password
    └── K8s 服务:     secretKeyRef → ipaas-secret
```

### 变量优先级

Ansible 变量优先级（从高到低）：
1. role `vars/main.yml` — 最高（**已全部移除密码定义**）
2. inventory `hosts` 文件 `[all:vars]` — **已删除密码行**
3. `group_vars/all/secrets.yml` — **唯一数据源**
4. role `defaults/main.yml` — 最低

### 密码获取方式

**Shell 脚本：**
```bash
source /data/maxs-ops/tools/password_lookup.sh
password=$(get_password ROOT_PASSWORD)
```

**Python 工具：**
```python
from tools.python.password_provider import get_redis_password
redis_pwd = get_redis_password()
```

**K8s 服务：**
```yaml
env:
  - name: DB_PASSWORD
    valueFrom:
      secretKeyRef:
        name: ipaas-secret
        key: mysql-password
```

| 存储位置                                        | 用途           | 格式                          |
| ------------------------------------------- | ------------ | --------------------------- |
| `inventory/group_vars/all/secrets.yml`      | 所有密码的单一数据源   | ansible-vault 加密            |

## 密码轮换流程

### 系统账户（root/asap）

```bash
# 生成新密码并轮换
./tools/rotate_system_passwords.sh --generate

# 或指定密码
./tools/rotate_system_passwords.sh --password 'NewP@ssw0rd!2024'

# 预览（不实际执行）
./tools/rotate_system_passwords.sh --generate --dry-run
```

流程：
1. 逐台服务器修改 root/asap 密码
2. 验证新密码 SSH 连接
3. 更新 server.txt / passwdmodify.txt
4. 更新 EM_SERVER_IP_LIST 数据库表
5. 全流程审计日志

### 第三方组件

```bash
# 轮换所有组件
./tools/rotate_component_passwords.sh --generate

# 轮换指定组件
./tools/rotate_component_passwords.sh --generate --component redis
```

各组件修改机制：

| 组件            | 修改方式                                        | 需重启  |
| ------------- | ------------------------------------------- | ---- |
| MariaDB/MySQL | `ALTER USER` SQL                            | 否    |
| Redis         | `CONFIG SET requirepass` + `CONFIG REWRITE` | 否    |
| Elasticsearch | `elasticsearch-reset-password`              | 否    |
| ClickHouse    | `ALTER USER` SQL                            | 否    |
| MinIO         | 环境变量                                        | 是    |
| Kafka         | `kafka-configs.sh` SCRAM                    | 滚动重启 |
|               |                                             |      |

### K8s Secret

```bash
./tools/update_k8s_secret.sh
```

重建 `ipaas-secret` 并导出到 `/data/images/ingress/ipaas-secret.yaml`。

## 部署注意事项

1. **生产部署前**：执行 `ansible-vault encrypt inventory/group_vars/all/secrets.yml` 加密密码文件
2. **vault 密码**：在操作机上创建 `/data/maxs-ops/.vault_pass`（或通过 ISO 分发）
3. **修改密码**：先运行 `generate_password.sh` 生成新密码，再运行 `rotate_system_passwords.sh` 进行轮换
4. **组件密码轮换**：建议在业务低峰期执行，部分组件（MinIO、Kafka、MongoDB）需要重启
5. **K8s pods**：更新 `ipaas-secret` 后需要重启相关 pods 使新密码生效
6. **回滚**：vault 文件初始值为旧密码，可通过 `ansible-vault edit` 恢复

## 业务代码改造指南

### Java 服务

```java
// ❌ 禁止
String password = "maxs.PDG~2022";

// ✅ K8s 部署：从环境变量读取
String password = System.getenv("DB_PASSWORD");

// ✅ 裸机部署：从配置文件读取
Properties props = new Properties();
props.load(new FileInputStream("/data/asap/config/db.properties"));
String password = props.getProperty("db.password");
```

### Python 服务

```python
# ❌ 禁止
PASSWORD = "maxs.PDG~2022"

# ✅ 推荐
from tools.python.password_provider import get_db_password
password = get_db_password()

# ✅ 或从环境变量
import os
password = os.environ.get("DB_PASSWORD")
```

### Pre-commit Hook

```bash
#!/bin/bash
# .git/hooks/pre-commit
if git diff --cached | grep -P 'password\s*[=:]\s*"[^"]{8,}"' --color=always; then
  echo "错误: 检测到可能的硬编码密码"
  exit 1
fi
```

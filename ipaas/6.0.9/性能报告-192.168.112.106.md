## 5. 磁盘 IO 分析

### 5.1 存储架构

```
sdb (SSD 894G) ─┐
                ├─ bcache0 (writeback mode) → /data (37T)
sda (HDD 36.4T) ┘
```

**bcache writeback 模式**：写入先到 SSD 缓存（sdb），后台异步刷到 HDD（sda）。SSD 承受全部写入压力，HDD 负责最终持久化。

### 5.3 分析

1. **SSD (sdb) 写入压力大但健康**：R2 轮瞬时写入达 42K w/s，延迟仅 0.37ms，SSD 性能充足
2. **bcache writeback 正在刷盘**：R2 轮看到 bcache0 有 32K w/s 的刷盘流量，说明 SSD → HDD 的后台写回正在进行
3. **HDD util% 偏高是 bcache 假象**：sda 的 util% 在 bcache 管理下可能不准确，且 `r/s` 和 `w/s` 极低（0~9 r/s, 0~7K w/s），实际延迟 0.26~0.42ms，**HDD 并未真正饱和**
4. **D-state = 0 确认无 IO 阻塞**：与 iostat 数据一致，存储响应正常

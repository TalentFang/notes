# 03 组件升级变量

## 变量机制

- 代码只做**大版本阈值判断**，小版本号按实际放入 `/data/asap/thirdSoft` 的包名填写。
- 切换阈值示例：`es_version >= 8`、`kafka_version >= 3.5`（KRaft）、`redis_version >= 8.0`、`k8s_version >= 1.36`。
- 仅 `redis_version` 已显式写入 inventory，其余均靠 `default()` 回退，需显式指定才切换。

## 一、运行时 / 控制变量（1 个）

| 变量                  | 默认值      | 切换值          | 用途                                                                                                                                     |
| ------------------- | -------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `container_runtime` | `docker` | `containerd` | 容器运行时切换：决定 k8s `criSocket`（`containerd.sock` vs `dockershim.sock`）、systemd 服务启停、transfer role（`transfer-docker`/`transfer-containerd`） |
## 二、版本变量（18 个）

### 核心中间件（6）

| 变量                    | 默认值           | 新版值     | 切换阈值                                                      |

| `keepalived_version`  | 2.0.20        | 2.4.3   | `>= 2.4.3` 走预编译，否则 RPM 旧版                                 |

## 三、特殊说明

- **JDK 无版本变量**：硬编码 `temurin-8-jdk`（`/usr/java/latest`，alternatives 默认）/ `temurin-21-jdk`（`/usr/java/java21`），靠 rpm 包预装。
- **containerd / nerdctl 无版本变量**：`nerdctl_file_name: nerdctl-2.3.4-linux-{{ architecture }}.tar.gz` 硬编码。

## 四、最小切换写法（`[all:vars]` 示例）

```ini
[all:vars]
container_runtime=containerd        # 切 containerd 运行时（可选）

es_version=8.19.19
kafka_version=3.9.2
kafka_scala_version=2.13
keepalived_version=2.4.3  
prometheus_version=3.13.1
elasticsearch_exporter_version=1.11.0
kafka_exporter_version=1.9.0
node_exporter_version=1.12.0
pushgateway_version=1.11.3


k8s_version=1.36.2
calico_version=3.32.1
ingress_nginx_version=1.15.1
webhook_certgen_version=1.6.9
etcd_version=3.6.8
registry_version=3.1.1
kube_state_metrics_version=2.19.1
metrics_server_version=0.9.0

# redis_version=8.2.8               # 已在 inventory 中
```

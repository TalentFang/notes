## 1. prometheus (2.41->3.5)

### 当前 Exporter

| Exporter               | 采集目标                                 | 部署范围                      |
| ---------------------- | ------------------------------------ | ------------------------- |
| node_exporter          | 主机OS指标（CPU/内存/磁盘/网络）                 | all_server（所有节点）          |
| kafka_exporter         | Kafka broker指标（消费延迟/topic/partition） | kafka_exporter 组          |
| keepalived_exporter    | KeepAlived VRRP 状态                   | nginx/flume/nfs 组，端口 9165 |
| elasticsearch_exporter | ES 集群指标                              | ES 节点                     |
| pushgateway            | Flink 推送指标（push 模式）                  | pushgateway 组             |
| ClickHouse 内置          | ClickHouse 指标                        | 直接 scrape `:9363`/`:9364` |
| kube-state-metrics     | K8s 资源状态                             | 端口 32500                  |

### 修改范围

* Exporter 与 Prometheus 之间通过 `HTTP /metrics` 端点通信，协议向后兼容，**不要求exporter配套升级**。
* Prometheus本身的配置文件中，有废弃字段，需要检查。



**修改范围**

| 文件                                               | 原因                                                     |
| ------------------------------------------------ | ------------------------------------------------------ |
| `prometheus.yml.j2`                              | 未使用 v2 废弃字段（`scrape_classic_histograms` 等），当前配置直接兼容 v3 |
| `run.sh.j2`                                      | 未使用已移除的 feature flags，无需改动                             |
| 各 exporter 的 `templates/*.j2` 和 `tasks/main.yml` | 启动方式、systemd 服务单元不受 Prometheus 版本影响                    |

### Prometheus 3.x 主要 Breaking Changes

| 变更项 | 当前代码是否受影响 |
| --- | --- |
| TSDB 格式变更（v3 仅兼容 v2.55+） | 监控数据可丢弃重建，不涉及迁移 |
| `scrape_classic_histograms` → `always_scrape_classic_histograms` | **不受影响**（当前未使用） |
| feature flags 移除（`utf8-name`、`native-histograms` 等） | **不受影响**（当前未设置） |
| PromQL 正则 `.` 匹配换行符行为变化 | 需验证 recording rules（`rules/*.yml`） |
| `remote_write` 中 `enable_http2` 默认值变更 | **不受影响**（当前未配置 remote_write） |

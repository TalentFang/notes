## 1. prometheus (2.41->3.13)

### 修改范围

* Exporter 与 Prometheus 之间通过 `HTTP /metrics` 端点通信，协议向后兼容，**不要求exporter配套升级**。

**编译命令：**

```
# 编译
export CC=gcc
export CXX=g++
export CFLAGS="-Wno-error"
export CXXFLAGS="-Wno-error"
make CC=gcc CXX=g++ CFLAGS="-Wno-error" CXXFLAGS="-Wno-error" BUILD_TLS=yes BUILD_WITH_MODULES=yes IGNORE_MISSING_DEPS=1 -j$(nproc) all

# 安装
make PREFIX=/data/comm/redis install
```

1. 当前glibc版本 2.28，不支持最新版本的containerd
![[Pasted image 20260728094021.png]]
2. 最新containerd(2.3.2版本)要求：
![[Pasted image 20260728105310.png]]

3. 解决方案
静态编译的包，不用系统的glic库

| 方面        | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **可行性**   | **技术上可行**，静态版本正是为 glibc < 2.35 的系统设计的[](https://github.com/containerd/containerd/releases?after=v1.0.0-alpha1)[](https://github.com/concourse/concourse/pull/9614)[](https://git.codeproxy.net/containerd/containerd/releases/tag/v2.3.2)。                                                                                                                                                                                                                                                                                                                                        |
| **优势**    | 解决了动态链接的 glibc 兼容性问题，提升了在不同发行版间的可移植性[](https://github.com/containerd/containerd/discussions/13340#dis)[](https://github.com/containerd/containerd/releases?after=v1.0.0-alpha1)。                                                                                                                                                                                                                                                                                                                                                                                                  |
| **风险与权衡** | 1. 安全更新需依赖官方发布新静态二进制，无法通过系统包管理器独立更新[](https://github.com/containerd/containerd/discussions/13340#dis)。  <br>2. 动态插件功能可能受限或被禁用[](https://go-mod-viewer.appspot.com/github.com/containerd/containerd@v22.0.0-20200918172823-438c87b8e050+incompatible/plugin/plugin_other.go)[](https://git.piicloud.cn/github/containerd/src/commit/3bc8fc4d3067c32d2580e716af095a837c0fbe9a/plugin/plugin_go18.go)[](https://github.com/containerd/containerd/pull/11203)。  <br>3. 在 Kylin 这类系统上，可能还需额外关注 cgroup 等配置的适配[](https://kubean-io.github.io/kubean/en/releases/v0.17.2/#whats-changed)。 |
**验证安装**
```
# 1. 服务状态
systemctl status containerd

# 2. 版本确认
containerd --version

# 3. 连接测试（containerd 默认通过 unix socket）
ctr --address /run/containerd/containerd.sock version

# 4. 列出命名空间
ctr --address /run/containerd/containerd.sock namespace ls

# 5. 拉取测试镜像（不运行容器）
ctr --address /run/containerd/containerd.sock image pull docker.io/library/hello-world:latest

# 6. 测试运行容器
ctr --address /run/containerd/containerd.sock run --rm docker.io/library/hello-world:latest test-verify

# 7. CRI 插件状态（K8s 真正用的接口）
crictl info | grep -A5 "status"
```

| 工具                | 命令                  | 说明              |
| ----------------- | ------------------- | --------------- |
| **iftop**         | `iftop -i eth0`     | 实时查看网络流量 TOP 会话 |
| **nload**         | `nload eth0`        | 实时查看网卡进/出流量     |
| **bmon**          | `bmon`              | 带宽监控工具          |
| **ifstat**        | `ifstat -t -d 1`    | 查看网卡流量统计        |
| **nethogs**       | `nethogs eth0`      | 按进程查看网络带宽占用     |
| **/proc/net/dev** | `cat /proc/net/dev` | 查看网卡累计流量        |
| **sar**           | `sar -n DEV 1 3`    | 网络统计            |

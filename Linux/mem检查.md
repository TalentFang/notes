| 工具                | 命令                  | 说明             |
| ----------------- | ------------------- | -------------- |
| **free**          | `free -h`           | 查看内存总量、使用量、可用量 |
| **top**           | `top` (按 M 排序)      | 按内存占用排序进程      |
| **htop**          | `htop`              | 彩色显示内存使用       |
| **vmstat**        | `vmstat 1 5`        | 查看内存和 swap 使用  |
| **smem**          | `smem -r`           | 更精确的内存使用统计     |
| **/proc/meminfo** | `cat /proc/meminfo` | 内存详细信息         |

| 工具         | 命令              | 说明                |
| ---------- | --------------- | ----------------- |
| **iostat** | `iostat -x 1 3` | 查看磁盘读写速度、利用率、等待时间 |
| **iotop**  | `iotop`         | 按进程查看磁盘 I/O 占用    |
| **dstat**  | `dstat -d`      | 综合统计，含磁盘 I/O      |
| **iostat** | `iostat -d 1`   | 只看磁盘读写速度          |
| **sar**    | `sar -b 1 3`    | 查看磁盘 I/O 统计       |
